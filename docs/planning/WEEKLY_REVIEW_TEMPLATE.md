## Definition of Done

A development task is generally Done when:

- implementation is complete
- relevant tests are added or updated
- architecture rules still pass
- formatting/static checks pass
- relevant documentation is updated when the change affects behavior or architecture
- no known regression is being hidden
- the change is committed to source control
